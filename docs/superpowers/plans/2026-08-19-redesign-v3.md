# Redesign v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 Lorescape App 改成 v3 結構——探索地圖當首頁、地球儀搬進書架頁、每日故事與收藏整組移除、書架與付費牆接回來（非訂閱者每日免費一篇）。

**Architecture:** 前端是 Flutter feature-first ＋ Clean Architecture（`app/` / `core/` / `shared/` / `features/`），路由用 go_router 扁平註冊，狀態用 Riverpod。後端是 FastAPI，額度擋點放在 `POST /narration`，真實來源是 Supabase 的 `daily_usage` 表與兩支 SECURITY DEFINER RPC。刪除類的 task 以「`analyze` 零問題 ＋ 全測試綠」當驗收，行為類的 task 走 TDD。

**Tech Stack:** Flutter（fvm）、Riverpod、go_router、easy_localization、Hive、Supabase、RevenueCat、FastAPI、uv、pytest

**Spec:** `docs/superpowers/specs/2026-08-19-redesign-v3-design.md`

## Global Constraints

- 一律用 `fvm` 執行 flutter / dart 指令。
- 每個 task 結束前 `cd frontend && fvm flutter analyze --fatal-infos` 必須零問題（含 infos）。
- 每個 task 結束前 `cd frontend && fvm flutter test` 全綠；動到 backend 的 task 另加 `cd backend && uv run pytest`。
- 依賴規則：feature 之間只能跨引他 feature 的 `domain/` 與 `providers.dart`；`data/`、`presentation/` 不得跨 feature 引用。守門測試 `frontend/test/architecture/dependency_rules_test.dart`。
- 文件以繁體中文撰寫（技術名詞除外）。
- Dart 專案的 package 名稱是 `context_app`（不是 lorescape），import 一律 `package:context_app/...`。
- i18n 兩個語系檔都要同步：`frontend/assets/translations/zh-TW.json`、`frontend/assets/translations/en.json`。
- 免費額度常數只有一個來源：backend `lorescape_backend/usage/policy.py` 的 `DAILY_FREE_LIMIT = 1`。
- Commit 訊息用繁體中文，格式 `type(scope): 說明`。
- 全程在 feature branch 上進行，不直接 commit 到 master。

```python
@router.post("", response_model=NarrationResponse)
def post_narration(
    request: NarrationRequest,
    config: Config = Depends(get_config),
    user: AuthedUser = Depends(require_user),
    cache: NarrationCacheRepository = Depends(get_narration_cache_repository),
    subscriptions: SubscriptionRepository = Depends(get_subscription_repository),
    usage: UsageRepository = Depends(get_usage_repository),
) -> NarrationResponse:
    """Return the long-form 3-paragraph story for the given place.

    Subscribers are unlimited. Everyone else gets DAILY_FREE_LIMIT
    narrations per calendar day (ADR 0009).

    The quota check runs *before* the cache lookup, and a cache hit
    consumes the quota just like a fresh generation: the product rule is
    "one story a day", not "one Gemini call a day". Otherwise picking a
    popular place would be unlimited and free, which hollows out the
    reason to subscribe.

    Generation failures do not consume quota — consumption happens only
    after a result is in hand.
    """
    is_premium = subscriptions.is_subscribed(user.user_id)
    if not is_premium and not has_free_quota(usage.used_today(user.user_id)):
        raise HTTPException(
            status_code=status.HTTP_402_PAYMENT_REQUIRED,
            detail="Daily free quota exhausted",
        )

    place_key = place_key_for(request)
    hook_id = hook_id_for(request)
    cached = cache.get(place_key, request.language, hook_id)
    if cached is not None:
        if not is_premium:
            usage.consume(user.user_id)
        return cached

    try:
        result = service.generate_narration(
            settings=config.genai_settings,
            request=request,
            web_search=config.narration_web_search_enabled,
        )
    except service.UnsupportedLanguageError as exc:
        raise HTTPException(status_code=400, detail=str(exc)) from exc

    cache.put(place_key, request.language, hook_id, result)
    if not is_premium:
        usage.consume(user.user_id)
    return result
```

- [ ] **Step 3: 加 pin provider**

```dart
/// 某本旅程的停點，只取有座標的記錄。舊記錄沒存座標（見
/// 20260819000000 migration），那些就不釘。
final tripGlobePinsProvider = Provider.family<List<GlobePin>, String?>((
  ref,
  tripId,
) {
  final entries = ref.watch(myJourneyProvider).valueOrNull ?? const [];
  return [
    for (final entry in entries)
      if (entry.tripId == tripId)
        if (entry.place.latitude case final lat?)
          if (entry.place.longitude case final lng?)
            GlobePin(
              id: entry.id,
              coordinate: LatLng(lat, lng),
              label: entry.place.name,
            ),
  ];
});
```

`myJourneyProvider` 是 `FutureProvider.autoDispose<List<JourneyEntry>>`；`LatLng` 來自 `package:latlong2/latlong.dart`。
