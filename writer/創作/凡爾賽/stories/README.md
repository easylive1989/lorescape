### 🔑 來源真相：現在是 `story.json`

轉檔已完成，**八篇一律以 `story.json` 為唯一來源**，`script.md` 由
`story_tool.py render` 產生（檔頭寫著 `status: generated`）。
**設定表與檢核表在各篇的 `README.md`。**

> ## 🔴 這條規矩是踩坑換來的
> `script.md` 一度**既是撰稿來源、又是 render 的產物**。抽驗 6️⃣ 時順手跑了一次
> `render`，就把手寫的設定表與檢核表蓋掉了（內文完好，因為 render 是從
> story.json 產生的）。
>
> **兩道修法都已落地**：
> 1. 設定與檢核搬到 `README.md`，`script.md` 從此純產物、可任意重生
> 2. `md2story.py` 拒絕吃 `status: generated` 的檔案——**產物不能回餵轉檔工具**

### 轉檔工具鏈（一次性，已完成任務）

| 工具 | 做什麼 | 為什麼分開 |
|---|---|---|
| `製作規範/md2story.py` | 切場、切 ≤60 字節點、認 `BG:`／`SFX:`／`FULL:`／`立繪:`／對白／選項／`IF` 條件段 | **純機械**。一篇 5,000 字手工切 350 個節點必然出錯 |
| `產圖腳本/build_stories.py` | 補變數、角色、背景對應、BGM、結局判定 | **設計**。這些寫在 SPEC 裡，**不從 markdown 猜**——猜錯會靜默壞掉 |
| `產圖腳本/distribute_bg.py` | 依 story.json 宣告的背景分發 | 背景不需要對應表，story.json 自己就宣告了 |
| `產圖腳本/distribute.py` | 分發立繪與 CG，並把 sprites 填回 characters | 檔名不同，需要對應表 |

**改劇本請改 `story.json`，再跑 `render`。前兩支工具不會再用到**——除非日後
新增第九篇，那時要在 `SPEC` 補一筆並從新的手寫 markdown 轉一次。

### 🔴 轉檔階段抓到的三個錯

| 錯 | 症狀 | 誰抓到的 |
|---|---|---|
| 選項同時有 `then` 與 `goto` | 跳轉被引擎靜默吃掉，場尾炸「走到底但不是結局」 | **走訪測試**（`story_tool.py check` 原本驗不到，已補上 1.5 節） |
| `IF 選了…` 條件段被攤平成直線 | 同一個決定被問兩次，**6️⃣7️⃣ 各有一個結局永遠到不了** | **走訪測試**的「三個結局全部可達」 |
| 結局門檻互相遮蔽 | 8️⃣ 的結局 B 不可達 | 同上 |

> **三個都只有把引擎實際跑起來才驗得出來。** 這就是走訪測試跨包跑的價值——
> 新的包沒有它守著，等於沒進引擎。

> ⚠️ **2️⃣ 的劇本在上層目錄**，因為它同時是垂直切片的 L4 工作文件（含 [[第一篇_場景清單]]）。比照龐貝。
> **製作序見 [[凡爾賽群像人物盤點]] §3**：2️⃣ → 1️⃣ → 4️⃣ → 3️⃣5️⃣6️⃣ → 7️⃣ → 8️⃣。🔑 **6️⃣ 必須排在 5️⃣ 之後**。

| 3️⃣ | 中尉、**瑪格麗特**（＝2️⃣ 主角，首次露臉） |
| 5️⃣ | 士官 |
| 6️⃣ | 修樹的老頭 |
| 7️⃣ | 女人甲、女人乙（媽媽沿用瑪格麗特） |
| 8️⃣ | 清點的人（熱維太太沿用 4️⃣） |

**可削減處**：7️⃣ 的女人乙可改為只有聲音、不出立繪 → 15 個。

> 🔑 **真正的發現不是數字，是模式**：**兩位主角（瑪格麗特、艾提安）在別篇需要立繪。**
> 群像結構下，「主角不做立繪」這條規則**只在自己那一篇成立**。估算時要把它算進去——龐貝也是這樣（菲勒蒙是 1️⃣ 的立繪、8️⃣ 的主角），但盤點層的表格沒有反映這件事。

## 5.3 🔴 引擎契約：選項的 `then` 與 `goto` 互斥

轉 2️⃣ 進引擎時踩到的：**`story_player.dart` 的 `choose()` 只要看到 `option.then`
非空就進 `then`，`goto`／`branch` 完全不會被執行。**

兩者同時給，跳轉會被靜默吃掉，然後在場尾炸「走到底但既沒有 next 也不是結局」
——**而且只有實際跑引擎才炸得出來**，`story_tool.py check` 原本驗不到。

**已修**：這條規則加進 `story_tool.py` 的 check（1.5 節），往後在轉檔階段就擋下。
**寫法**：要跳轉的選項不寫 `then`，把那幾句旁白移到目標場的開頭。
