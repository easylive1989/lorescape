## 1. 這個專案在做什麼

**手機直式視覺小說**，龐貝主題，繁體中文。

- **形式**：10–15 分鐘短篇，**一個故事一個資料夾**
- **SKU 單位**：**景點包**（一個地點 × 一個時刻 × 8 篇群像短篇 × 一套共用背景庫）
- **實作**：Flutter（由 user 自己寫），資料驅動——引擎只讀 `story.json`
- **美術**：AI 生成（Codex CLI 的 `image_gen`）

**最重要的三份規格文件**，接手前先讀：

| 文件 | 內容 |
|---|---|
| [[產品規格書]] | 形式、SKU、規模推導、對既有定價方案的修正 |
| [[Flutter製作規範]] | **實作端唯一規格來源**：版面數值、`story.json` schema、必備功能、測試清單 |
| [[美術風格聖經]] | 風格、直式版面、AI 出圖的正面約束與考據驗收清單 |
| [[龐貝史實紅線]] | ✅史實／⚠️爭議／⬜空白 三層分級，全案的史實邊界 |

## 5. 工具

`story_tool.py` 是**跨景點包共用**的，在 `製作規範/`；`產圖腳本/` 綁龐貝的 prompt，在 `創作/龐貝/`。兩者都**換機會跟著 vault 一起過去**。

### `story_tool.py`——驗證與轉檔

```bash
cd .../lorescape
python3 製作規範/story_tool.py check  創作/龐貝/stories/01_港口的外地人   # 驗證
python3 製作規範/story_tool.py render 創作/龐貝/stories/01_港口的外地人   # 產 script.md
```

`check` 驗：節點字數上限、資產參照是否存在、未宣告的角色與背景、跳轉目標、**結局可達性**。

> **`story.json` 是唯一來源，`script.md` 一律由它產生。** 改劇本改 json，然後 render。不要手改 `script.md`。

### `產圖腳本/`——AI 出圖

| 腳本 | 用途 |
|---|---|
| `genbg.sh` / `genbg2.sh` | 直式背景（9:16） |
| `genchar2.sh` / `genchar3.sh` | 立繪基底（2:3） |
| `genexpr.sh` / `genexpr2.sh` | 表情差分（image-to-image，以基底為輸入） |
| `distribute.py` | 把 `美術測試/` 的定版圖分派進各故事資料夾，並清理 `missingAssets` |

用法都是 `./genXXX.sh <key> [<key> ...]`，key 見腳本內的 `case`。**風格聖經的 prompt 骨幹寫死在這些腳本裡**——要改風格改腳本，不要臨時另寫 prompt。

## 6. 換機後的驗收指令

```bash
cd .../project/lorescape

# 1. 八篇是否都通過（應全部 ✅ 通過、零警告）
for d in 創作/龐貝/stories/0*/; do printf "%-22s " "$(basename $d)"; \
  python3 製作規範/story_tool.py check "$d" 2>&1 | tr '\n' ' '; echo; done

# 2. 圖檔數量對不對（預期 bg/sprite 依序如下）
for d in 創作/龐貝/stories/0*/; do printf "%-22s bg=%-2s sprite=%-2s\n" "$(basename $d)" \
  "$(ls $d/assets/backgrounds|wc -l)" "$(ls $d/assets/sprites|wc -l)"; done
```

**預期值**：01 → 9/13｜02 → 5/7｜03 → 4/8｜04 → 7/10｜05 → 7/10｜06 → 5/10｜07 → 4/8｜08 → 4/5

若 `check` 出現「檔案不存在」的警告，就是 Sync 沒帶到圖 —— 原始檔全部在 `創作/龐貝/美術測試/`，重跑 `distribute.py` 即可補回。

## 7. 接手時最容易踩的坑

1. **不要手改 `script.md`**——它是產生出來的，下次 render 會被蓋掉。
2. **不要臨時寫新的出圖 prompt**——風格靠腳本裡寫死的骨幹維持一致。第 5 輪就是因為換了措辭導致立繪跑成攝影風，整批作廢。
3. **`codex` 回報「已完成」不等於檔案存在**——它的檔案複製會滯後。**一律以 `ls` 確認**。第 6、7 輪各踩過一次。
4. **批次腳本不要用 `exec "$0"`**——`cd` 之後相對路徑解不到，會 exit 127。已改用 `SELF="${0:A}"`。
5. **AI 出圖：正面指定 > 負面提示**——負面清單擋不掉模型的預設值。維蘇威的山形一定要正面描述成「單一完整綠錐」，否則它會畫成今天那個缺一角的樣子。
6. **第 7 篇的老普林尼是史實人物**——不可救活、不可改變艦隊已知行動結果。全包紅線最緊的一篇。

## 8. 建議的下一步

**做第 1 篇的垂直切片。**

不是全部八篇一起做，是**一篇完整跑通**：載入 `story.json` → 背景 ＋ 立繪 ＋ 對話框 → 選項與變數 → 三個結局 → 存讀檔。

理由：這是唯一能把「一篇要花多久」從估算變成實測的方法，而那個數字決定上架節奏，上架節奏決定訂閱制成不成立（[[產品規格書]] §7）。

音訊可以先全部靜音——`missingAssets` 已列好，引擎照著降級即可，不會崩。
