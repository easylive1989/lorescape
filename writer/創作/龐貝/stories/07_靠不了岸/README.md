## 這一篇在講什麼

**POV**：老普林尼艦隊的一名水手（虛構）（**主角不做立繪**）

**戲劇問題**：*你出發是為了救人，結果你只是看著——這樣算什麼？*

**設計重點**：全包唯一的**外部視角**。前六篇都在城裡往外看，這篇從外面往裡看——讓讀者第一次看見整座城的全景。
