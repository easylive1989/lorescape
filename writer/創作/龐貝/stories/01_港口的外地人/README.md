## 這一篇在講什麼

一名亞歷山卓商行的敘利亞僱員，必須在明天午後開船前收回卡住的貨款。

**戲劇問題**：*你會為了別人的財產多留一天嗎？*

**能動性契約**：主角**有離開的自由**——這是整個景點包第 1 篇必須立下的東西：**你改不了火山，但你能決定這個人在最後二十四小時裡成為什麼樣的人。**

**手法**：戲劇反諷。**全篇不出現「災難」，只出現徵兆**，而每一次徵兆都被一個合理的解釋蓋過去——讀者認得出來，主角不認得。這不是技巧，是史實：當時沒有人擁有解讀它的框架。

### 變數的作用

- **`affection` 情分**——**決定結局分支**（留下時 ≥2 走 C、否則走 B），並改寫 S07 的維比婭橋段
- **`awareness` 察覺**——**不決定結局**，只改寫 S08 與結局 C 的不安程度

> `awareness` 是本篇的主題裝置：**察覺拉滿的玩家，看到的是一個把所有徵兆都注意到了、卻仍然無法解讀的人。**

## 實作端必做的三件事

1. ~~**轉 WebP**~~——**上架前再做即可**（2026-08-13 確認）。開發期直接用 PNG，目標約 5 MB 留到送審前
2. **立繪去背 ＋ 對齊**——表情差分有輕微飄移，需以**兩眼中點與眼距**對齊；菲勒蒙的基底框取較近，需整體縮小
3. **缺件降級**——`cg_column_rising`（結局 A 的噴發柱）與全部音效尚未產出，不得因此崩潰

詳見 [[Flutter製作規範]] §4、§8。
