## 這一篇在講什麼

**POV**：維比婭（麵包坊女業主）（**主角不做立繪**）

**戲劇問題**：*在一切都要結束的那天，你仍在為明天做打算——這件事是可笑還是尊嚴？*

**設計重點**：全篇不出現火山，直到最後一格。張力全在戲劇反諷——讀者知道今天是最後一天，她不知道。
