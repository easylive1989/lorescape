## 這一篇在講什麼

**POV**：管理帳務蠟板的家內奴隸（虛構）（**主角不做立繪**）

**戲劇問題**：*你要帶走別人的財產，還是自己的自由？*

**設計重點**：全包最漂亮的機關——那批蠟板在現實中真的被挖出來了。**兩個結局都成立，因為史實只記錄了物，沒記錄人。**
