## 這一篇在講什麼

**POV**：十歲左右的自由民之子（虛構）（**主角不做立繪**）

**戲劇問題**：*大人們的臉色是什麼意思？*

**設計重點**：資訊不對稱做到極致——玩家比主角知道得多太多。全包情感濃度最高，也最短。
