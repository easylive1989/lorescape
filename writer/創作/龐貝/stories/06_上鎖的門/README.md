## 這一篇在講什麼

**POV**：角鬥士營房的雜役少年（虛構）——**不是角鬥士本人**（**主角不做立繪**）

**戲劇問題**：*被當作財產的人，值得先救嗎——如果決定權在你手上？*

**設計重點**：⚠️ 規避原則：不寫角鬥士當主角、不寫他跟貴族少女戀愛。電影《龐貝》(2014) 已把那條線寫盡。**改用雜役視角，看的是同一群人，但問的問題完全不同。**
