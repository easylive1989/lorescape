## 這一篇在講什麼

**POV**：菲勒蒙（魚醬作坊的被釋奴，第 1 篇的買方）（**主角不做立繪**）

**戲劇問題**：*你保住了一切，除了你是誰。*

**設計重點**：**第四幕由這篇獨自承擔。** 沒有它，整個景點包只是一場毀滅；有了它，主題才完成。被釋奴的身分讓「你是誰」有雙重意義——他本來就是靠一座城才變成人的。
