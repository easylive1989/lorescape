## 判讀

1. **上週的 P0「landing 追蹤是否斷了」有了答案：不是全斷，是幾乎沒流量。**
   `landing_cta.csv` 本週回來一列（8/20，1 次點擊、1 人），證明事件管線仍在運作；
   其餘六天是真的沒有人點。Landing 活躍用戶 1→6 也是同一個結論——問題不在追蹤，
   在流量本身太小。**這條 P0 可以結案，改列 P1 觀察。**

2. **App 端本週是全報告最強的訊號，而且來源不是 IG。** first_open 8→32、
   Android 新用戶 6→27、iOS 下載 2→8，但同期 IG 觸及還跌了 17%、App Store 曝光
   跌 45%。流量沒有變多，**轉換率卻明顯變好**：商品頁瀏覽 9→15（曝光只有前週的
   55%），代表看到的人更願意點進商品頁。這批新用戶從哪來，現有欄位答不出來，
   是本週最重要的待查項。

3. **App Store 曝光 −45% 但下載 +300%，兩者背離。** 曝光縮水通常伴隨下載縮水，
   這次反向，指向商店頁本身（截圖／副標／關鍵字）或某個外部導流管道發生了變化。
   若下週仍維持，值得回頭確認 8/11 上架的版本是否改動了商店素材。

4. **「裝了不聽」變成「聽了不完」。** 上週 narration_start 是 0，本週恢復到 6 人——
   埋點與產品路徑都通。但 `narration.csv` 顯示 started 6 / completed **0** /
   abandoned **6**，完成率 0.0%，六個人全部中離。這比上週的「完全沒人開始」更
   難解釋：使用者找得到播放入口、也按了，卻沒有一個聽完。**這是目前唯一的 🔴。**

5. **D1 留存 0，cohort 卻放大到 42 人。** 前幾週 cohort 只有 1–10 人時，留存 0
   還可以用樣本太小解釋；本週 42 個新用戶、隔天回訪 0 人，這個數字開始有意義了，
   且與判讀 4 指向同一件事——首次體驗沒有留住人。

6. **IG 轉換率回升但仍未過關。** 0.46% → 0.73%，是四週來第一次回升，且個人檔案
   瀏覽 30→40、粉絲增速 +21→+35 三個指標同向。上週 P0 動的 bio 與片尾 CTA 值得
   繼續觀察一週再判斷是否為真效果。但 0.73% 距離 1.5% 門檻仍有一倍差距，
   **依 calendar 判準 3（連續低於門檻即不調整選點），本週題材配比續不動**——
   這已是第五週觸發。

7. **Carousel 連三週探底（中位 33 → 28，最高只有 85）。** 上週 P1 列的「要不要繼續發」
   已經沒有起色可等。7 支 carousel 的總觸及 242，不到單支中位 reel 的一半。

## 行動清單

### 本週立即處理（P0）

- **查清 narration 完成率 0 的原因**（唯一 🔴）。6 人開始、6 人放棄、0 人完成，
  且 D1 留存同步為 0。先確認是播放失敗（TTS/音檔載入錯誤、網路中斷）還是內容
  太長導致中離——前者是 bug，後者是產品決策。這決定下週要修的是程式還是內容。
  建議路由：`marketing-retention` 看留存與事件序列，必要時配合 `lorescape-debug`
  查 narration API 是否有 402/5xx。

- **找出本週 32 個 first_open 的來源。** Android 新用戶單週 27 人、IG 觸及卻在跌，
  這批人不是 IG 來的。查 Play Console 的 acquisition 報表（`store_android.csv` 的
  `store_listing_visitors` / `store_listing_acquisitions`）與 GA4 的
  session_source，確認是自然搜尋、某次外部曝光，還是預載/測試流量。
  **若這是一個可重複的管道，它比 IG 現在的 0.73% 轉換率更值得投資源。**

### 下週觀察（P1）

- **IG bio / 片尾 CTA 改版的效果**：0.46%→0.73% 是四週來首次回升，但一週不足以
  判定。下週（8/31）看是否守住 0.7% 以上；若回落即視為雜訊。
- **Landing 流量**（原 P0 降級）：追蹤已證實正常，剩下的是流量太小。等 App 端
  來源查清後，再決定要不要動 `marketing-landing-page`。
- **App Store 曝光 −45% 與下載 +300% 的背離**：下週若下載守住、曝光續跌，
  就要正式查商店素材與關鍵字。
- **周間 vs 週末發布時段**（上週 P1 續追）：本週最高的兩支是 8/17（週日，2,201）
  與 8/21（週四，1,388），**週末優勢這週不成立**，樣本仍不足以改排程，繼續記錄。

### 本週該做的決定

- **Carousel 是否降級。** 連三週觸及中位 < 35、本週 7 支合計僅 242。建議把 carousel
  改為「只服務既有粉絲的補充內容」，製作流程簡化（不再逐張審稿），把省下的時間
  移到 reel 的 hook 與片尾 CTA。這是決策題不是資料題，需要你拍板。
