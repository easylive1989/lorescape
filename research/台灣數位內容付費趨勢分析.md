# 台灣數位內容付費趨勢分析

> **問題**：台灣人願意為數位敘事內容付錢嗎？趨勢是變好還是變壞？
> **為什麼要問**：[[營收天花板與地板估算報告]] 的所有情境都建立在「付費轉換率」這個參數上，而該參數目前完全是外部借用值。本文試圖從台灣本地的實際趨勢為它建立判斷基礎。

---

## 0. 核心結論

**台灣不是「不願付費」，是「付費意願高度依賴形式」。**

兩個並存的事實證明了這一點：

| 悲觀訊號 | 樂觀訊號 |
|---|---|
| 文策院 2023：閱讀器使用者僅 **18% 願付費** | LINE WEBTOON 台灣 **MAU 逾 200 萬**，2018 推出付費後流量與營收持續成長 |
| 電子書僅占出版市場 **6–8%** | 台灣 Podcast 付費 **年增四倍** |
| 紙本出版 74% 新書結構性虧損 | 電子書新書出版量**年增近一倍**，閱讀器帶動業績翻倍 |

**同一群人，換一種形式，付費行為完全不同。** 所以問題不是「台灣市場行不行」，是「你選的形式對不對」。

---

## 1. 紙本出版：結構性崩壞

| 指標 | 數字 |
|---|---|
| 出版社數量 | **845 家**（文策院 Q3 2025），單季增 146 家 |
| 微型業者 | **62%** 只出 1–4 種書，貢獻 13% 新書量 |
| 新書年產量 | 30,000 – 35,000 種 |
| **首刷 2,000 本以下占比** | **74%** |
| 首刷中位數 | **已跌破 1,800 本** |
| 退書率 | **30% – 50%** |
| **實際銷售中位數** | **900 – 1,260 本** |
| **損益平衡點** | **2,200 本** |
| 年圖書零售額 | 約 200 億元 |
| 年新增滯銷庫存 | 約 3,800 萬冊 |
| 現金流週期 | 付印到收款 **150 – 180 天** |
| 時報文化五年複合成長率 | **0.3%** |

**74% 的新書首刷量未達損益平衡點——這不是景氣問題，是結構問題。** 業內說法是「以書養書的時代已經結束」。

成本端同時惡化：紙漿印刷漲 15%、人事成本漲 10%、數位廣告競價上升。

### 1.1 這對 LoreScape 是個有用的參照尺

把 [[營收天花板與地板估算報告]] 的中位情境（年營收約 **24 萬**）換算成出版業的語言：

- 一本 NT$ 400 的書，出版方約可分得 40% ≈ NT$ 160/本
- 年營收 24 萬 ≈ **賣掉 1,500 本書的毛利**
- 而紙本書的**實際銷售中位數是 900–1,260 本**

**中位情境的營收，大約等於一本中位數以上的紙本書。**

但差別在於：你不用付印刷費、不用吃 30–50% 退書率、沒有 3,800 萬冊滯銷庫存的產業共業、也沒有 150–180 天的現金流缺口。

**這不是說數位比較好賺，而是說：中位情境的數字放在出版業的脈絡裡，其實是正常水準，不是失敗。**

## 2. 三條逆勢成長曲線

### 2.1 電子書：載體驅動的成長

| 指標 | 數字 |
|---|---|
| 市佔率 | **6–8%**（2024 年估 4–6%，仍在上升） |
| 2025 Q4 電子新書出版量 | 博客來／讀墨／Kobo 三大平台 **4,571 種**，較前一年同期**幾乎翻倍** |
| Readmoo 會員 | **突破 200 萬**（2026 上半年） |
| Readmoo 2026 上半年 | 會員閱讀時間與營收**雙雙成長逾 20%** |
| 博客來 BooksPad 閱讀器 | 上市首月帶動電子書業績**翻倍** |
| 電子書製作成本 | 僅 **3,000 – 5,000 元**／本 |
| 平台抽成 | 30 – 40% |

**關鍵觀察：成長是「載體」驅動的，不是「內容」驅動的。**

BooksPad、mooInk 這類閱讀器上市直接帶動業績翻倍，書展排隊主力也是電子書閱讀器攤位。這說明——**閱讀體驗的改善能直接釋放既有的付費意願**。

> 📌 **對 LoreScape 的直接意涵**：app 的閱讀體驗設計**不是加分項，是核心變數**。同樣的內容，介面體驗的差距可以造成倍數級的營收差異。

**另一個細節**：電子書暢銷榜**翻譯書占 82%**，遠高於紙本新書的 27%。電子書讀者的口味明顯偏向翻譯書——**本土原創內容在電子書通路的表現，可能弱於整體市場數字所暗示的**。這對本土歷史題材是個警訊。

### 2.2 網路條漫：最貼近的可比對象 ⭐

**LINE WEBTOON 是本文找到的最重要對照——它幾乎就是 LoreScape app 的形式原型。**

| 指標 | 數字 |
|---|---|
| 台灣 MAU | **逾 200 萬** |
| 進入台灣 | 2014 年 |
| 推出付費搶先看 | **2018 年** |
| 付費上線後 | **使用者未因收費下滑，流量與營收持續成長** |
| 用戶年齡 | 24 歲以下 **50%**、25–34 歲 **28%**（34 歲以下合計 78%） |
| 男女比 | 4 : 6（**女性偏多**） |
| 變現機制 | 免費 ＋ **代幣解鎖搶先看** ＋ 看廣告 |

業內說法：**「台灣人口相較美國、歐洲、東南亞少，但付費接受度算是相對高。」**

**為什麼這是最好的對照：**

| | LINE WEBTOON | LoreScape 互動短篇 |
|---|---|---|
| 載體 | 手機 | 手機 ✅ |
| 消費單位 | 單話，數分鐘 | 單篇，10 分鐘 ✅ |
| 供給節奏 | 定期更新 | 定期上架 ✅ |
| 變現 | 免費 ＋ 代幣解鎖 | 免費 ＋ 包／訂閱 ✅ |
| 視覺呈現 | 有圖（條漫） | **有圖**（滿版背景 ＋ 立繪）✅ |
| 畫面方向 | **直式** | **直式** ✅ |
| **關鍵差異** | 平台規模 ＋ 韓國 IP 庫存 | **單一創作者、從零起步** ⚠️ |

> 📌 **更正（2026-08-11）**：本文初版將「有圖 vs 純文字」列為與條漫的關鍵落差。該前提**已失效**——LoreScape 實品為**直式滿版背景 ＋ 角色立繪 ＋ 文字框**的視覺小說（美術由 AI 生成），與條漫同為直式、有圖、免費入場的手機敘事。
>
> **真正的差異改為：平台規模與內容庫存。** LINE WEBTOON 的 200 萬 MAU 建立在十年經營與韓國 IP 庫存之上，單一創作者從零起步不能假設能複製同樣的觸及。**形式可比，規模不可比。**

但它至少證明了一件事：**「手機 ＋ 碎片化敘事 ＋ 免費入場 ＋ 付費解鎖」這個模式在台灣是可行的，而且做到了 200 萬 MAU 的量級。** 這比 [[美景聽聽案例分析]] 的台灣數字有參考價值得多。

### 2.3 聲音經濟：小基期高成長

| 指標 | 數字 |
|---|---|
| 台灣 Podcast **付費**年增 | **四倍** |
| 2024 全台付費訂閱金額 | 突破 **600 萬元** |
| 創作者累計收入 | 逾 **2,800 萬元** |
| Podcast 廣告收入年增 | **逾 70%** |
| 聽眾偏好類型 | 商業、知識、自我成長 |
| 地域集中度 | 台北市占全台收聽量 **68%**，雙北逾七成 |

**成長率驚人，但基期極小。** 全台 Podcast 付費訂閱總額 600 萬——這是**整個市場**的數字，不是單一節目。

> 📌 這替 [[敘事體驗產品價格研究報告]] §7 路徑 D（聲音化）標定了現實尺度：台灣的聲音付費市場**還在孵化期**，適合當作內容的二次利用管道，不適合當作主要收入來源。

**另一個可用資訊：台北 68% 的收聽集中度。** 若日後做在地歷史內容或實體導覽，雙北是唯一有規模的主戰場。

## 3. 逆風：訂閱疲勞

| 指標 | 數字 |
|---|---|
| Z 世代對訂閱感到疲憊 | **87%** |
| 近期取消至少一項訂閱 | **37%** |
| 計畫縮減訂閱數量 | **29%** |
| **把訂閱當「短期租賃」**（追完即退） | **59%** |
| Z 世代平均訂閱數 | 3.51 個 |

> ⚠️ **重要限制：以上為美國調查數據**（CivicScience、IGN 研究報告），由台灣媒體轉載。**不可直接套用台灣**，僅供方向參考。

**但有一個台灣本地數據與之呼應**：近半數有付費訂閱的台灣民眾，**訂閱後沒有使用服務，或使用頻率非常低**。

台灣訂閱滲透率參考：影音串流 44%、美食外送 31%、音樂串流 26%、雲端 19%。

### 3.1 對訂閱方案的實質威脅

[[互動歷史短篇App定價方案]] §3.3 的 NT$ 90/月 訂閱面對兩個問題：

1. **「短期租賃」行為模式**：用戶訂一個月把內容看完就退訂。對內容庫有限的新產品，這是致命的——他們一個月就能看完你半年的產出。
2. **訂閱數飽和**：Z 世代平均已有 3.51 個訂閱，新訂閱是零和競爭。

**這強化了 [[美景聽聽案例分析]] §5 已經提出的警告，並指向同一個結論：**

> **全通行證 NT$ 690（一次買斷、永久）的戰略地位應該上調。** 它同時順應「訂閱疲勞」與「買斷回歸」兩個趨勢——實體媒體與買斷制的回歸，正是這股疲勞的另一面。

## 4. 環境面的順風

**2025 年全球非遊戲 App 消費者支出暴增 21%，達 856 億美元，首度超車手遊的 818 億美元**（Sensor Tower《2026 行動市場報告》）。

內容型 app 的付費環境正在改善，資金與注意力正從遊戲流向工具與內容。這對「不是遊戲、但在 App Store 賣內容」的產品是結構性利多。

另外，台灣 Google Play 2025 年度榜單中，有兩款台灣團隊原創遊戲入榜（《哥布林也想談戀愛》獲年度最佳獨立製作、《Go Gull: Tile Match》獲年度最佳台灣製作）——**台灣獨立團隊在自家市場仍有被看見的通道**。

## 5. 五個判讀

### 5.1 付費意願不是問題，形式才是

「18% 願付費」與「LINE WEBTOON 200 萬 MAU」並存，不是矛盾，是答案：**同一群人在不同形式上的付費行為完全不同**。

不要用電子書的悲觀數字推論你的產品，也不要用條漫的樂觀數字。**要問的是：你的形式更像哪一個？**

### 5.2 數位的成長是存量轉移，不是增量

出版零售總額約 200 億基本停滯（時報五年複合成長 0.3%），電子書從 4–6% 升到 6–8%——**成長來自紙本讀者遷移，不是新讀者進場**。

意思是：**你在跟其他內容搶同一批既有讀者的時間與錢包**，不是在開發新客群。

### 5.3 體驗設計是營收變數，不是加分項

閱讀器上市就讓電子書業績翻倍。載體體驗的改善能直接釋放既有付費意願——**這是本文對產品開發最直接的建議**。

### 5.4 訂閱要防「短期租賃」，買斷順應趨勢

訂閱疲勞（雖為美國數據）與台灣「近半訂閱後不用」的現象同向。**內容庫深度不足時，訂閱會被當成一個月的租賃用完即退。**

全通行證的地位應上調；訂閱開通的 30 篇門檻更不能妥協。

### 5.5 本土原創在數位通路的表現可能弱於整體數字

電子書暢銷榜**翻譯書占 82%**（紙本新書僅 27%）。數位閱讀通路的口味明顯偏向翻譯書——**本土歷史題材要有心理準備**。

## 7. 資料限制

| 資料 | 可信度 | 說明 |
|---|---|---|
| 出版市場結構數據（首刷、退書率、BEP） | **中高** | 引自文策院 Q3 2025 與中原印刷 2025 統計，經第三方文章整理 |
| 電子書出版量年增近倍、市佔 6–8% | **中高** | 文策院季度報告 |
| Readmoo 200 萬會員、+20% 成長 | **中** | 官方宣稱；「會員」為**註冊**數（含海外），非付費者 |
| **訂閱疲勞 87% / 59% / 37%** | **不適用於台灣** | **美國調查**（CivicScience、IGN），台灣媒體轉載。僅供方向參考 |
| LINE WEBTOON 台灣 MAU 200 萬 | **中低** | 來自廣告代理商行銷資料，**時點不明**，未經官方財報驗證 |
| 「台灣付費接受度相對高」 | **低** | 業內受訪說法，**非量化數據** |
| Podcast 付費年增四倍、600 萬 | **中** | Firstory《2025 趨勢報告》，為 2024 年數據 |
| 非遊戲 App 超車手遊 | **中** | Sensor Tower 推估，全球數字非台灣 |
| §1.1 的書籍毛利換算 | **低** | 分潤比例 40% 為概略假設，各出版社差異大 |

**最大的資料缺口**：**沒有任何「台灣原創手機視覺小說」的付費數據**。條漫是平台型且有韓國 IP 庫存、電子書是既有出版品、Podcast 是聲音——三者都不完全等同於本產品。這個缺口只能靠實際驗證填補（見 [[回饋預測力檢查表]]）。
